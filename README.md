# 🍕 Pizza Ordering App

A streamlined **SwiftUI** application for browsing menus and ordering pizzas, featuring real-time state management and location services.

## ✨ Key Features
* **Dynamic Menu:** Browse and select pizzas with real-time state updates.
* **Map Integration:** Built-in **MapKit** support to display locations using precise Latitude and Longitude coordinates.
* **Modern State Management:** Leveraging `@StateObject` and `@Published` for seamless UI synchronization.

## 🏗 Architecture & Tech Stack
* **Framework:** SwiftUI
* **Design Pattern:** **MVVM** (Model-View-ViewModel) for clean, testable code.
* **Maps:** MapKit for coordinate-based annotations.



## 🚀 Quick Start
1. Clone the repository.
2. Open the `.xcodeproj` file in **Xcode**.
3. Press `Cmd + R` to build and run on a simulator.
